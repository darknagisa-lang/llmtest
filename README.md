# AI Product Intelligence Platform

Streamlit Community Cloud 배포 설정은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

Streamlit 기반의 신제품 반응 분석 프로토타입입니다. 기존 고객 문의 분석은 왼쪽 페이지 메뉴의 **기존 고객 문의 분석**에서 사용할 수 있습니다. 가상 자료는 실제 소비자 반응이 아닙니다.

## 신제품 리뷰 탐색

리포트 **개요 → 제품 주요 사양**에는 일치하는 모델의 제조사 공개 사양과 공식 제품 사진이 표시됩니다. 기본 등록 모델 외에는 **제조사 사양 찾기**로 공식 페이지를 찾고 **제품 사양·공식 사진 등록**에서 모델별로 한 번 저장할 수 있습니다. GSMArena는 사용자 등록 참고 자료로 구분하며, 제품 사진에는 제조사 이미지만 사용합니다.

첫 화면 오른쪽의 **주목할 만한 리뷰**는 최근 7일의 브랜드 및 AI 기기 리뷰를 검색하고, 후보가 적으면 장기 사용기 검색을 30일까지 넓혀 제품을 최대 5개 고릅니다. 제목에 나타난 장기 사용, 동일 게시 연령대 내 다른 제품 대비 높은 조회수, 최소 3개 고유 채널에서의 등장 중 하나 이상을 선정 근거로 사용합니다. 조회수는 검색 표본에서 측정한 스냅샷입니다. **검색 설정 → 주목할 만한 리뷰**에서 YouTube 분석·외부 전송 범위와 OpenAI 비용을 확인한 뒤 자동 선정을 켭니다. 등록된 오전 8시 Windows 작업의 다음 실행부터 갱신되며, 첫날은 화면의 **오늘의 주목할 리뷰 선정**으로 바로 갱신할 수 있습니다. 성공한 결과는 같은 브리핑에서 재사용합니다. 후보가 부족하면 5개 미만을 표시합니다. **이 제품 분석하기**를 누르면 댓글 수집과 분석을 실행할 수 있는 제품 상세가 열립니다.

상세 분석의 비율은 유효 댓글을 분모로 계산합니다. 디스플레이 관련 근거가 있으면 댓글별 분석 후 GPT-6 Luna가 종합 제안을 한 번 생성합니다. **디스플레이 기획** 탭에서 세부 항목별 반응, 유지할 강점, 개선 우선순위, 차세대 기회와 검증 방법을 확인할 수 있습니다. 각 제안에는 댓글 원문 링크가 연결됩니다. 종합 요청이 실패해도 개별 분석은 계속 표시됩니다.

첫 화면 **08시 신제품 브리핑**은 한국 시간 오전 8시를 기준으로 직전 24시간의 리뷰를 한국어·영어 통합 검색으로 확인합니다. 제품을 사전에 등록할 필요가 없습니다. 검색 결과에서 모델명을 식별한 뒤 폰, 태블릿, 워치, 웨어러블, 노트북 등으로 표시합니다. 검색 색인 및 모델명 인식 범위 때문에 일부 제품은 빠질 수 있습니다. 카드에는 제목에서 직접 확인되는 스펙 언급과 출처가 표시됩니다. 제조사 사양을 확인한 경우 **리뷰 살펴보기 → 제조사 스펙 등록**에서 수치와 출처를 저장할 수 있습니다.

왼쪽 페이지 메뉴에서 **신제품 리뷰 탐색**을 선택합니다. 앱 페이지를 열거나 조작할 때 등록 제품의 검색 결과가 없거나 24시간이 지났으면 최근 24시간의 영상을 검색합니다. 관심 제품과 키워드, 한국어·영어, 검색 기간, 영상·댓글·분석 건수는 **검색 설정**에서 바꿀 수 있습니다. 기본값은 영상 20개와 영상당 댓글 100개입니다. 카드의 최근 영상은 검색 결과일 뿐 신제품 출시나 전문 리뷰를 보증하지 않습니다.

카드의 **리뷰 살펴보기**를 누르면 영상·댓글만 수집하거나, 승인 및 전송 권한과 API 비용에 동의한 뒤 **리뷰 수집 및 분석 시작**을 누를 수 있습니다. 댓글 분석 결과는 같은 화면에 나타나고 원문과 링크를 확인할 수 있습니다. YouTube 데이터 분석 권한이 필요한지 먼저 확인하세요. 영상 자막·발언 내용은 일반적으로 가져오지 못하며, 영상 제목이나 설명을 리뷰어의 평가로 간주하지 않습니다.

프로그램을 닫은 동안에도 매일 오전 8시(한국 시간)에 YouTube 검색만 실행하려면 먼저 `run.bat`을 한 번 실행해 가상환경을 만든 후, 프로젝트 폴더에서 PowerShell로 `powershell -ExecutionPolicy Bypass -File .\register_daily.ps1`을 실행하세요. 이 명령은 현재 Windows 사용자에 `ProductIntelligenceDailyCheck` 작업을 등록합니다. 해당 작업은 OpenAI 호출을 하지 않습니다. 삭제하려면 Windows 작업 스케줄러에서 해당 이름의 작업을 삭제하세요. 컴퓨터가 꺼져 있으면 정각 실행은 불가능하며, 등록 설정에 따라 가능한 시점에 실행됩니다. 이 작업은 자동 등록되지 않습니다.

검색 카드의 YouTube 영상 메타데이터는 `review_cache.json`에 저장되고 24시간이 지나면 앱이나 일일 검색이 다음에 실행될 때 만료·삭제됩니다. 사용자 설정은 `product_settings.json`에 저장됩니다. 두 파일은 Git에서 제외됩니다. 댓글과 댓글 분석 결과는 새 화면의 세션 메모리에만 보관되며 30분 후 다음 화면 갱신 시 만료됩니다.

## 설치 및 실행

1. Python 3.10 이상을 설치하고 PATH에 추가합니다.
2. `.env.example`을 참고해 같은 폴더의 `.env`에 `OPENAI_API_KEY`와 필요한 경우 `YOUTUBE_API_KEY`를 입력합니다. YouTube 키만 들어 있는 `2.env` 파일도 지원하며, `.env`의 YouTube 키가 우선합니다. 기존 파일은 덮어쓰지 마세요. `OPENAI_MODEL`을 생략하면 `gpt-6-luna`입니다. 키 파일은 공유하거나 Git에 올리지 마세요.
3. `run.bat`을 더블클릭합니다. 가상환경 생성 및 패키지 설치 후 브라우저가 열립니다. 또는 `.venv\Scripts\python.exe -m streamlit run app.py`를 실행합니다.
4. **Data Collection → 가상 데이터 → 가상 데이터 불러오기**를 누르면 비용 없이 화면을 체험할 수 있습니다. 종료는 실행 콘솔에서 Ctrl+C를 누르세요.

모바일에서는 PC와 같은 네트워크에 연결한 뒤 실행 콘솔에 표시되는 Network URL로 접속합니다. 방화벽 설정에 따라 연결이 제한될 수 있습니다. 이 앱에는 로그인 기능이 없으므로 신뢰할 수 있는 네트워크에서 사용하세요.

## 데이터와 분석

- CSV: 권리가 있는 자체 자료를 업로드하고 내용 열과 제품을 선택합니다. 외부 전송·요금에 동의한 후 분석할 수 있습니다. 한 행당 최대 12,000자만 전송하며 최대 건수를 지정할 수 있습니다. 분석 결과는 세션 메모리에 보관되고 필터링된 CSV를 Reports에서 다운로드합니다. 실패 시 완료된 결과만 남으며 재시작 시 처음부터 다시 분석합니다. 기존 CSV 문의 분석은 별도 메뉴에 보존되어 있습니다.
- PDF: 이미지 PDF의 첫 페이지를 이미지로 렌더링하여 OpenAI에 전송하고 구조화된 분석을 표시합니다. 다중 페이지 일괄 요약은 아직 지원하지 않습니다.
- YouTube: 새 제품 탐색 화면과 기존 분석 대시보드의 Data Collection에서 검색할 수 있습니다. YouTube 파생 분석 승인, OpenAI 전송 권한, API 비용을 확인한 경우에만 댓글 분석을 수행합니다. 체크박스는 YouTube 승인을 대신하지 않습니다. 영상의 제목·설명 메타데이터와 시청자 댓글·대댓글을 별도로 표시합니다. 댓글과 분석 결과는 메모리에 보관되며 다운로드나 다른 출처와의 합산은 제공하지 않습니다. 검색 카드용 영상 메타데이터는 위에 설명한 24시간 디스크 캐시를 사용합니다.
- 네이버는 사용자의 요청에 따라 제외했습니다. YouTube 또는 네이버 API 결과를 자체 CSV/PDF로 우회 업로드해 분석하지 마세요.

## 키 발급 및 제한

- OpenAI: [API 키 관리](https://platform.openai.com/api-keys)에서 발급하여 `.env`에 `OPENAI_API_KEY`를 설정합니다. Settings에서 비용 발생에 동의한 뒤 연결 테스트를 할 수 있습니다. 분석은 호출 횟수 제한과 출력 토큰 제한을 사용하지만 정확한 달러 상한은 보장하지 않습니다. [현재 요금](https://platform.openai.com/pricing/)과 계정의 사용 한도를 확인하세요.
- YouTube: [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성 → YouTube Data API v3 사용 설정 → 사용자 인증 정보에서 API 키 발급 → 키의 API 제한 설정 → `.env`에 `YOUTUBE_API_KEY` 추가 후 재실행합니다. 로그인·약관·결제 설정 등이 필요할 수 있습니다. 키가 없으면 가상 데이터 모드를 이용할 수 있습니다. YouTube 수집 버튼 자체가 연결 테스트입니다.
- [YouTube 할당량](https://developers.google.com/youtube/v3/determine_quota_cost): 기본값은 search.list 하루 100회와 나머지 메서드 합산 하루 10,000단위입니다. 페이지네이션과 대댓글은 추가 호출을 사용합니다. 실제 프로젝트 한도는 콘솔에서 확인하세요.
- YouTube의 [파생 지표 정책](https://developers.google.com/youtube/terms/derived-metrics-policy) 및 [정책 가이드](https://developers.google.com/youtube/terms/developer-policies-guide)는 감성 분석 등 일부 파생 지표에 감사와 승인을 요구합니다. 외부 LLM 전송, 상업적 활용, 다른 출처와 결합의 허용 여부도 별도 검토가 필요합니다. 앱의 차단은 승인 취득 절차를 대신하지 않습니다. 배포 전 이용약관·개인정보처리방침과 데이터 처리 전반에 대한 검토가 필요합니다.

## 현재 제한

분석은 행 단위 순차 호출이며 중간 취소와 금액 기반 강제 상한, 백그라운드 작업, 영구 저장, 대량 배치 API는 구현되지 않았습니다. 차트 클릭 대신 기능 선택으로 근거를 확인합니다. 기능별 차트에는 처음 두 기능만 표시하고 전체 구조화 결과는 분석 JSON에 보존합니다. 출시 전후 자동 구간 비교, 발표일, D+1/3/7/14/30 통계, 이슈 급증 탐지, 국가 확인, 전문 보고서 작성 기능은 아직 구현되지 않았습니다. 작성자의 국적과 구매 여부는 확인되지 않으며 구매 의향은 모델의 추정입니다. 외부 API 장애나 할당량 초과 시 결과가 일부만 표시될 수 있습니다.

## 테스트

`.venv\Scripts\python.exe -m unittest -v test_platform test_product_hub`으로 가상 데이터 화면, 구조화 스키마, YouTube 모의 페이지네이션 및 제품 선택부터 결과까지를 검사합니다. 모의 테스트는 실제 YouTube 인증·수집 성공을 의미하지 않습니다.
